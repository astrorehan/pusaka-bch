# Technology logos

The hero's "Built with" row credits technology used by Pusaka. Marks are self-hosted and rendered in grayscale; the original files and their geometry are preserved.

| File | Source |
| --- | --- |
| `bitcoin-cash.svg` | [Bitcoin Cash graphics](https://bitcoincash.org/en/graphics/), [original circle mark](https://bitcoincash.org/img/green/bitcoin-cash-circle.svg) |
| `solidcash.svg` | [SolidCash](https://solidcash.org/), [original logo](https://solidcash.org/img/logo.svg). The square image viewport displays the coin mark at the left of the original artwork; the adjacent name is ordinary page text. |
| `wizardconnect.png` | The embedded 60 by 60 PNG from `@wizardconnect/react` 0.2.6, [`packages/react/src/components/logo.ts`](https://gitlab.com/riftenlabs/lib/wizardconnect/-/blob/master/packages/react/src/components/logo.ts) |
