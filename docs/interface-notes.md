# Pusaka interface

The app uses a collapsible desktop sidebar, a compact tablet rail and a phone drawer.
Balance and recent activity occupy the main column; inheritance rules stay visible beside them.
Owner, trusted contact and heir actions are derived from live chain state.
Every spending action opens a transaction review before asking the connected wallet to sign.
Warm neutral surfaces, the Pusaka flower and restrained green highlights carry the existing identity.
The landing page remains separate from the working wallet.
